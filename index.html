Mobile OTG Connection Guide

  • Android: Use a USB OTG cable/adapter with Google Chrome or Microsoft Edge. Enable OTG connection in phone settings if your brand requires it.
  • iPhone / iPad: iOS Safari does not support the browser Web Serial API over USB/OTG. Use an Android phone or a laptop/desktop browser (Chrome/Edge) for live serial streaming.
  • NFC Tag Tip: After tapping your NFC tag on Android, ensure it opens in Chrome (not an in-app preview) so Web Serial can prompt for the USB port.
